```python
import smac
from smac.facade import SMACFacade

# Define the problem and the search space
problem = smac.Problem("my_problem")

# Initialize the SMAC framework
smac_facade = SMACFacade(problem)

# Perform the search process
smac_facade.run()

# Get the best configuration
best_config = smac_facade.get_best_config()

# Evaluate the best configuration
best_config.evaluate()

# Print the results
print("Best configuration:", best_config)
```

This example demonstrates how to use the `smac` library to automate the search process for a machine learning problem. The `SMACFacade` class provides a simple interface for performing the search, and it returns the best configuration and its evaluation metrics.
